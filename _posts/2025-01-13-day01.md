HTML, React, CSS, JS
	=> 가장 대중적임, 오류가 없음, 가장 완벽하게 돌아감

VSCode 기본적 사용법
	우리가 사용할 폴더를 제작

HTML
	Hyper Text Markup Language
	글자로 표현하는 표현식
	이미지인지 글자인지 구분이 되도록 부속어를 작성
	명확한 규칙대로 작성해서 원하는 표현이 무엇인지를 알 수 있도록 만드는 방법 => HTML
	이 규칙을 특정 언어로 작성하면 문제가 생김

HTML의 규칙
	1. 첫 줄에 <!DOCTYPE html>을 적어야 한다 (마크업 언어 중 html을 사용하겠다는 의미)

	2. 첫 줄에 적는 <!DOCTYPE html>을 제외한 나머지는 열림과 닫힘이 쌍으로 존재해야 한다 (없으면 디자인이 뭉개질 수 있음)
		2 - 1. 마크업 언어에 적는 내용은 Tag로 구성 ex) <Tag>: 열림 태그 </Tag>: 닫힘 태그
		2 - 2. 간혹 쌍이 아닌 경우가 존재 -> </Tag> (열림 태그와 닫힘 태그가 합쳐진 싱글 태그)

	3. Tag는 정해진 이름이 있고 그 이름은 소문자로 작성한다
		3 - 1. <Tag>에 적히는 이름은 아무거나 적으면 안된다
			ex) html, head, body, meta, ...
		3 - 2. 정해진 이름 작성시 소문자로 적어야 한다
			ex) <Tag> X, <tag> O

	4. 각각 Tag 중 몇몇개는 용도가 정해져 있다
		4 - 1. 대표적으로 html, head, body가 존재
				html -> 전체적인 tag들이 전부 들어갈 태그, 이 태그 안에 나머지 태그들을 작성해 나간다
				head -> html 태그 안에 눈에 보이지 않는 정보(사이트 제목 등..)를 작성하는 태그
						보이지 않는 내용의 태그가 작성되는 구간을 의미함 => 단순 텍스트를 적으면 보이게 된다!
						보이지 않는 태그 중 대표 -> <title></title> (제목)
				body -> html 태그 안에 눈에 보이는 정보를 작성하는 태그
						<html> <head></head> <body></body> </html>

html 실행해서 확인하는 방법
	F5(웹앱 -> 크롬, 엣지 중에 하나 고르기)


단축키

	alt + Arrow(Up, Down) -> 줄 이동
	alt + shift + Arrow(Up, Down) -> 줄 복사
	ctrl + alt + shift + Arrow(Up, Down) -> 여러 줄 수정
	ctrl + space -> 어시스트

확장

	Indent Rainbow -> 줄 색 변경
	Prettier -> 자동 포매팅 (오타 줄이는 용도)
	Auto Close Tag -> 닫힘 태그 자동 생성"
